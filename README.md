# Perturbation-status estimation benchmark

Omnibenchmark plan for Papalexi 2021, Norman 2019, and Replogle 2022.
Mixscape, Mixscale, and PS are benchmarked as perturbation-status estimators.
Target expression is computed only inside the engagement metric as a reference
quantity and is not exposed as a fourth method.

The local host backend intentionally calls the frozen project environments.
Repository URLs can be changed to the `tmp-perturb` remotes after review without
changing the pinned module commits.
